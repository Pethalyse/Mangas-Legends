# MangaLegends

MOBA 5v5 entre amis, avec des héros de mangas et d'animés. Unity 6 LTS, C#, multijoueur Photon Fusion 2 (serveur autoritaire, client prédictif).

Le projet est en **refonte complète**. L'ancien prototype (2023, Mirror) reste consultable dans `Legacy/` et dans l'historique git.
